# 测试实例使用说明

| 文件 | 用途 | 在页面哪个Tab使用 |
|------|------|-------------------|
| `test_sentences.md` | 37条分类测试句，含翻译/润色/转换/评估 | 全部Tab（复制粘贴使用） |
| `batch_test_cn.txt` | 中文多段落文本（5段） | Tab 5「批量处理」上传测试 |
| `batch_test_en.txt` | 英文多段落文本（5段） | Tab 5「批量处理」上传测试 |
| `eval_test_data.json` | 7组参考译文vs候选译文对照 | Tab 4「质量评估」参考数据 |

## 快速测试流程

### 1. 翻译测试
打开 Tab 1「翻译」，从 `test_sentences.md` 复制以下句子：
- **中→英**: 句子 1-10 中的任意一条
- **英→中**: 句子 11-15 中的任意一条
- **中→日**: 句 16-17
- **中→韩**: 句 18-19

切换不同「翻译策略」看效果差异。

### 2. 润色测试
打开 Tab 2「学术润色」，复制：
- 句 20-22 (英文口语→学术)
- 句 23-25 (中文口语→学术)

切换「润色级别」（轻度/中度/重度）看差异。

### 3. 口语/书面语转换
- 口语→书面语: 复制句 26-30
- 书面语→口语: 复制句 31-33

### 4. 质量评估
- 自动评估: 从 `eval_test_data.json` 取 reference 和 candidate_a 填入
- 人工打分: 对照 source→reference→candidate 依次评分

### 5. 批量处理
上传 `batch_test_cn.txt` 或 `batch_test_en.txt`，选择语言对和策略后开始批量翻译。

### 6. 对比实验
在 Tab 6 选择实验类型→设置样本数→运行。
