# 翻译质量评估模块 — 测试样例与操作指南

============================================================
功能一：单条自动评估（BLEU / METEOR）
============================================================

【操作步骤】
  评估 Tab → 点"单条评估" → 翻译方向 中→英
  → 输入原文 → 点"先翻译" → 自动填入模型翻译
  → 输入参考译文 → 点"计算 BLEU & METEOR"

【预期结果】

============================================================
功能二：批量评估
============================================================

【操作步骤】
  评估 Tab → 点"批量评估"
  → 测试样本数: 10
  → 翻译方向: 中→英
  → 领域: 全部领域（或选"学术"测单领域）
  → 评估策略: 意译 → 意译参考
  → 点"开始自动评估"

【系统自动执行】
  从默认语料库（546条，7领域）分层抽样 10 条
  → 模型逐条翻译
  → 与语料库自带的英文参考对比
  → 汇总平均 BLEU / METEOR

【预期显示】
  表格：原文 | 模型翻译 | 参考译文 | BLEU | METEOR
  顶部统计卡片：平均 BLEU（如 35.2）| 平均 METEOR（如 0.52）

【变体测试】
  - 改领域为"医学" → 只测医学领域语料
  - 改样本数为 20 → 更多样本更稳定
  - 改评估策略为"直译 → 直译参考" → 语料自带 en_literal 参考


============================================================
功能三：人工评分
============================================================

【操作步骤】
  评估 Tab → 点"人工打分"
  → 填入源文本 + 模型翻译结果 + 参考译文（可选）
  → 拖动三个滑块评分（1-5分）
  → 勾选错误类型（如有）
  → 点"提交评分"

├──────────────────────────────────────────────────────────┤

============================================================
系统自动评估 vs 人工评分的协同使用
============================================================

  先用「批量评估」快速扫描 50 条翻译 → 看平均 BLEU/METEOR
  → 对异常低分的样本 → 点「人工打分」深入看具体错误类型
  → 提交评分后 → 点「反馈分析与提示优化建议」
  → 系统自动汇总错误类型分布 + 生成优化建议
